# utility-models-persistence Spec

**Ticket ID:** `utility-models-persistence`

## Feature Summary

Persist utility model assets (Whisper speech recognition, MiniLM ONNX model, ONNX vocab, and future `UtilityType` values) in a dedicated Room table with UUID primary key, separate DAO and repository, and full Firestore sync mirroring `local_models`. Wire runtime call sites—especially `UtilityModelFileResolver`—to read metadata from Room instead of calling `ModelConfigFetcher.fetchRemoteConfig()` on every path resolve.

**Root cause (verified):** `UtilityModelFileResolver` calls `modelConfigFetcher.fetchRemoteConfig().getOrThrow()` on every `resolveUtilityModelPath` invocation. Utility assets are not persisted: `InitializeModelsUseCase` passes `utilityAssets` only to `CheckModelsUseCase` for filesystem scan; `SyncLocalModelRegistryUseCase` rejects empty configurations; `local_models` has no `utility_type` and treats zero-config rows as soft-deleted LLMs.

**Approved design:** Separate `utility_models` table (not `local_models`) to avoid colliding with soft-delete semantics (`getSoftDeletedModels` = zero configs) and `getAllActive` (requires configs).

**End-to-end pipeline:**

1. **Init/download:** `InitializeModelsUseCase` / `DownloadFinalizeWorker` fetch remote catalog (network allowed).
2. **Persist:** Valid on-disk utility files upsert into `utility_models` with `pending_sync = 1`.
3. **Upload:** Firestore pending-sync engine uploads local changes to `users/{uid}/utility_models/{id}`.
4. **Offline read:** `UtilityModelFileResolver` reads Room + validates filesystem; **no network**.
5. **Download apply:** Firestore sync down merges remote rows by `updated_at`; resolver continues to work offline.

**Offline policy (explicit):**

| Call site | Network |
| --- | --- |
| `UtilityModelFileResolver.resolveUtilityModelPath` | **Forbidden** — Room + filesystem only |
| `InitializeModelsUseCase` | Allowed — catalog refresh at startup |
| `DownloadFinalizeWorker` | Allowed — finalize after download completes |
| Firestore sync replay/listener | Allowed — cloud hydration |

If Room has no row for a `UtilityType`, resolver returns `null` (callers already handle missing paths). Remote catalog is **not** fetched as a resolver fallback.

**Upgrade path:** Fresh install or reinstall only. No Room migration and no backfill for existing on-disk files. Bump `EnclaveDatabase` to version `7` and rely on existing `fallbackToDestructiveMigration(dropAllTables = true)` in `DataModule` if the app is upgraded without reinstall (local DB is wiped; user is expected to reinstall instead).

## API Contracts

### Domain IDs

```kotlin
@JvmInline
value class UtilityModelId(val value: String)
```

- Generated as `Uuid.random().toString()` when `metadata.id.value.isEmpty()` on upsert.
- Firestore document ID equals `UtilityModelId.value`.

### Domain Model — `UtilityModelMetadata`

```kotlin
data class UtilityModelMetadata(
    val id: UtilityModelId,
    val utilityType: UtilityType,           // non-null; one row per type
    val huggingFaceModelName: String,
    val remoteFileName: String,
    val localFileName: String,
    val sha256: String,
    val sizeInBytes: Long,
    val modelFileFormat: ModelFileFormat,
    val source: DownloadSource = DownloadSource.HUGGING_FACE, // domain-only; not stored in Room/Firestore
)
```

### Port — `UtilityModelRepositoryPort`

```kotlin
interface UtilityModelRepositoryPort {
    suspend fun getByUtilityType(utilityType: UtilityType): UtilityModelMetadata?
    suspend fun getAllActive(): List<UtilityModelMetadata>
    fun observeAllActive(): Flow<List<UtilityModelMetadata>>
    suspend fun getById(id: UtilityModelId): UtilityModelMetadata?
    suspend fun getBySha256(sha256: String): UtilityModelMetadata?
    suspend fun upsert(metadata: UtilityModelMetadata): UtilityModelId
    suspend fun softDelete(id: UtilityModelId)
}
```

**Upsert rules:**

1. If row exists for `utilityType` (active), reuse its `id` unless incoming `id` matches existing.
2. If row exists for `sha256` (active) with different `utilityType`, update that row only when `updated_at` logic in sync handler applies; repository upsert prefers `utilityType` lookup first.
3. Set `pending_sync = 1`, `deleted = false`, `updated_at = System.currentTimeMillis()`.
4. Call `CloudSyncTrigger.trigger()` after write.

**Soft delete:** Sets `deleted = 1`, `pending_sync = 1`, bumps `updated_at`. Does not delete filesystem files (same as `local_models`).

### Use Case — `SyncUtilityModelRegistryUseCase`

```kotlin
class SyncUtilityModelRegistryUseCase @Inject constructor(
    private val utilityModelRepository: UtilityModelRepositoryPort,
    private val logger: LoggingPort,
) {
    suspend operator fun invoke(asset: LocalModelAsset): UtilityModelId
}
```

**Behavior:**

1. `require(asset.metadata.utilityType != null) { "Not a utility asset" }`
2. Map `LocalModelAsset.metadata` → `UtilityModelMetadata` (copy `utilityType` as non-null).
3. `utilityModelRepository.upsert(...)` and return id.
4. Log: `"SyncUtilityModelRegistry(${utilityType}): sha=${sha256} file=${localFileName}"`.

Does **not** call `SyncLocalModelRegistryUseCase`.

### Port — `UtilityModelFilePort` (unchanged signature)

```kotlin
interface UtilityModelFilePort {
    suspend fun resolveUtilityModelPath(utilityType: UtilityType): String?
}
```

**New `UtilityModelFileResolver` behavior:**

1. `utilityModelRepository.getByUtilityType(utilityType)` — if null → return null.
2. Resolve `File(modelsDir, metadata.localFileName)` with existing `safeFile` guard.
3. Return absolute path iff file exists **and** `file.length() == metadata.sizeInBytes`.
4. **Never** inject or call `ModelConfigFetcherPort`.

### Room Entity — `UtilityModelEntity`

Table name: `utility_models`

| Column | SQL type | Notes |
| --- | --- | --- |
| `id` | TEXT PK | `UtilityModelId` |
| `utility_type` | TEXT NOT NULL | `UtilityType.apiValue`; **UNIQUE** among active semantics enforced by unique index |
| `model_file_format` | TEXT NOT NULL | `ModelFileFormat.name` |
| `huggingface_model_name` | TEXT NOT NULL | |
| `remote_filename` | TEXT NOT NULL | |
| `local_filename` | TEXT NOT NULL | |
| `sha256` | TEXT NOT NULL | Indexed (non-unique) |
| `size_in_bytes` | INTEGER NOT NULL | |
| `updated_at` | INTEGER NOT NULL | Epoch millis |
| `pending_sync` | INTEGER NOT NULL DEFAULT 0 | `0=synced`, `1=pending`, `2=claimed` |
| `deleted` | INTEGER NOT NULL DEFAULT 0 | `0=active`, `1=soft-deleted` |

**Indices:**

- `index_utility_models_sha256` on `sha256`
- `index_utility_models_utility_type` **UNIQUE** on `utility_type`

### Firestore Collection

- Path: `users/{uid}/utility_models/{utilityModelId}`
- Collection name constant: `"utility_models"`

**Field mapping (mirror `local_models` + `utility_type`):**

| Firestore field | Room column | Type |
| --- | --- | --- |
| *(document id)* | `id` | string |
| `utility_type` | `utility_type` | string (`UtilityType.apiValue`) |
| `model_file_format` | `model_file_format` | string |
| `huggingface_model_name` | `huggingface_model_name` | string |
| `remote_filename` | `remote_filename` | string |
| `local_filename` | `local_filename` | string |
| `sha256` | `sha256` | string |
| `size_in_bytes` | `size_in_bytes` | number |
| `updated_at` | `updated_at` | number |
| `deleted` | `deleted` | boolean |

No sensitive fields; no encryption in sync handler.

**Conflict resolution (same as `LocalModelSyncHandler`):**

- On download apply: if local row missing OR remote `updated_at >= local.updated_at`, upsert with `pending_sync = 0`.
- Else skip with debug log.
- Dedup: match existing by `id`, then by `utility_type`, then by `sha256`.
- Delete event: `softDeleteById`.

## Schema (version 7, no incremental migration)

Define `utility_models` on `UtilityModelEntity` (Room generates DDL on create). Bump `EnclaveDatabase` `version = 7`, register entity and DAO. **Do not** add `MIGRATION_6_7` to `EnclaveDatabaseMigrations.kt`.

- **Fresh install / reinstall:** Room creates `utility_models` with indices from entity annotations.
- **In-place app update without reinstall:** Existing `fallbackToDestructiveMigration(dropAllTables = true)` in `DataModule` drops and recreates all tables; user must re-download models. No special backfill from disk.
- Run `./gradlew :app:kspDebugKotlin` to export schema `7.json`.

**Init persist (not backfill):** On each successful `InitializeModelsUseCase` catalog fetch, persist utility assets whose files are valid on disk (`sha256` not in `modelsToDownload`). This is the normal first-run path after reinstall, not an upgrade backfill.

## Drift / Escalation Rules

1. **Schema drift:** If implementation requires columns beyond this spec (e.g., `huggingface_path`, multimodal fields), stop and request Contract Waiver before merging.
2. **Shoehorn attempt:** Do not store utilities in `local_models` or add `utility_type` to `local_models`. Escalate if tempted.
3. **Resolver network call:** Any `ModelConfigFetcherPort` usage in `UtilityModelFileResolver` is a spec violation (mutation-defense tests must fail).
4. **Sync parity:** If `utility_models` uploads but Functions allowlist omits it, stop and fix allowlist before completion.
5. **Soft-delete collision:** If utility rows appear in `getSoftDeletedModels()` or slot activation paths, revert and fix routing.
6. **Empty-config sync:** Do not call `SyncLocalModelRegistryUseCase` for utilities (empty configurations throw).
7. **Human gate:** Do not merge production code until this plan and `test_spec.md` are human-approved (Synthitect Plan gate).
