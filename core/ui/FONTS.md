# Bundled UI fonts (`:core:ui`)

| File | Family | License |
|------|--------|---------|
| `res/font/ibm_plex_sans_*.ttf` | IBM Plex Sans | [OFL 1.1](https://openfontlicense.org/) |
| `res/font/source_serif4_*.ttf` | Source Serif 4 | [OFL 1.1](https://openfontlicense.org/) |

Latin subset files from [Fontsource](https://fontsource.org/) (v5.2.5) for reliable Compose Preview and offline use.

- **IBM Plex Sans** — app chrome, user bubbles, metadata labels (`EnclaveUiFontFamily`).
- **Source Serif 4** — assistant markdown body (`EnclaveReadingFontFamily` / `LlmBodyTextStyle`).
